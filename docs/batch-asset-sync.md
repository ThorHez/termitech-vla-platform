# 批量同步资产

在“数据与模型”列表左侧勾选多个资产，再点击“批量同步”。数据集、模型和归一化参数均可选择。表头可全选当前页中的可同步资产，切换筛选会保留其他已选项；选择区显示数量并提供清空入口。已归档、不可用或来源机器离线的资产不能新选。

1. 选择另一台在线目标机器，填写目标父目录，目录支持联想。
2. 检查每项的目标子目录名及完整目标路径。目录资产默认使用来源目录名，JSON 等文件资产默认使用资产名称；多个目标重名时需手工修改，不会自动覆盖。
3. 对已绑定有效 norm_stats 的数据集，默认勾选“一并同步已绑定的 norm_stats”，可逐项取消。没有关联、关联不可用的数据集不勾选。仅同步数据集时不会保留指向源机器 NORM 的绑定；勾选后在目标机器校验、登记统计量并重新绑定。模型和 NORM 也可作为独立资产勾选。
   模型项另有“不同步 train_state/”选项，默认不勾选，保持完整复制。勾选后仅跳过该模型目录根部的 `train_state/`，`params`、嵌套目录中的同名目录及其他文件仍保留。该目录若包含优化器等训练状态，排除后副本不包含这些状态；需要恢复完整训练状态时应保留。数据集与 NORM 不提供此选项。
4. 点击开始，控制台一次创建整批后台同步任务。源机器直传目标机器，控制台负责调度、校验和进度。关闭弹窗不会取消任务；每项都有自己的进度、日志、取消及重试入口，可在资产页同步列表或“后台任务”中查看。

一次最多创建 20 项，来源可以是多台机器，目标机器不能是任何所选资产的来源机器。同步复用已有 SSH 接入及文件校验流程；目标机器需要能访问各源机器的 SSH，两端需有可用的 rsync。文件内容直接在两台机器之间传输，不经控制台中转。最多并行传输 2 个任务；当前已有活动任务时，剩余容量可能少于 20。SSH 凭据、机器状态、允许目录及目标命名会在创建时统一检查；任一项无效则整批不排队，网络重试不会重复创建。

排队成功后，每项独立执行，部分失败不会取消已成功的副本。失败或中断的任务可单独重试，源文件保持原样，目标已存在的目录不会被覆盖。文件校验成功后才登记目标资产；副本用于训练时仍需训练预检。批量提交成功只表示任务已创建，不代表文件已经同步完成。

无法建立机器间直传时，任务会显示具体错误及日志，不会回退为控制台中转。请检查目标到源机器的 SSH 连通性、两端 rsync 和目录权限后再重试；取消仍通过对应任务的取消入口完成，已传部分文件继续保留供重试。

同步记录和日志在工作空间内共享可读。操作员只能取消、重试或删除自己创建的同步任务，管理员可处理全部任务；缺少创建者的历史任务仅管理员可操作。管理员重试时保留原创建者，并记录本次执行发起者为管理员；权限按本次执行发起者核对。已登记的公共目标资产由管理员维护，删除同步记录不删除目标资产或物理文件。

## API

`POST /api/v1/asset-transfer-batches` 需要个人会话、`assets.transfer` 权限和现有 CSRF 校验，客户端附带 `X-Asset-Transfer-Batch-User` 防止账号切换后提交旧表单。

```json
{
  "idempotency_key": "本账号本次提交的唯一标识",
  "target_node_id": "目标机器 ID",
  "target_directory": "/data/copied",
  "entries": [
    {
      "source_asset_id": "数据集资产 ID",
      "target_name": "cloth-a",
      "include_norm_stats": true,
      "expected_norm_asset_id": "当前绑定的 NORM ID"
    },
    {
      "source_asset_id": "模型资产 ID",
      "target_name": "base-model",
      "include_norm_stats": false
    }
  ]
}
```

返回 202，包含 `idempotency_key` 和 `transfers` 数组，各项结构与单资产同步接口相同。各项返回 `owner_user_id` 和 `execution_user_id`。后续通过现有 `/asset-transfers/{transfer_id}` 接口共享查询；取消、重试和删除需要 `assets.transfer`，并额外核对创建者或管理员身份。提交标识按账号隔离；相同标识重放同一请求返回已创建任务，不重新发起传输，修改请求内容需使用新标识。

模型项勾选排除时发送 `"exclude_train_state": true`；未勾选时省略该字段以保持既有请求兼容。单笔同步采用相同字段。任务结果保存此策略，列表和详情显示“排除 train_state/”；失败后重试沿用原策略，修改策略需新建同步任务。
