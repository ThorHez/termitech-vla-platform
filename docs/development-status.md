| 模块 | 当前能力 |
| --- | --- |

| 本地资产 | 数据、初始模型、归一化统计均绑定机器；拒绝跨机器组合；产出关联来源任务和执行代码 |
| 路径联想 | 登记资产时从所选机器 Agent 获取实际目录名，支持前缀、目录下钻及键盘选择；请求防抖/取消、权限与离线提示、真实路径越界过滤 |
| Agent 与 Runner | 主动登记和心跳、持久化命令/事件、独立训练进程、重复 START 去重、取消和退出确认 |
| 监控 | 主机 CPU/内存/磁盘、NVML GPU 指标、训练进程树资源、训练指标与日志；采集失败显示未知 |
| 代码追溯 | 每次实际启动保存完整 Git SHA、分支、修改摘要、实际模块路径和本地修改证据；与预检基线比对 |
| 运行恢复 | Agent 重启后重新发现存活 Runner、补传事件；Runner 丢失时进入 UNKNOWN 等待对账 |
| 训练适配 | 可实际运行的 CPU 链路测试；OpenPI SFT wrapper；ReCap 价值函数与离线 ACP 两阶段配置、阶段适配及 Agent 自动预检 |
| 配方选择 | 接入机器无需配方；创建训练时选择，预检/提交/启动绑定同一配方；Agent 自动预检，兼容旧默认值与历史验收记录 |
| 自动训练预检 | Agent 使用指定训练解释器解析本次配方及修订，检查本机数据、归一化参数、模型、入口、输出空间与 GPU 配置；结果绑定本次请求，提交与实际启动复核，无需人工配方名单 |
| 配方联想 | 按所选机器及训练环境静态读取 OpenPI 配方注册列表，关键词包含匹配（忽略大小写、开头优先）、点击及键盘填入；代码来源、逐项验收状态、动态发现限制及离线回退提示 |
| 配方库 | 分组详情与源码查看、10 个常用数值字段编辑、差异预览、另存和不可变修订；训练绑定修订及来源指纹，原代码不回写 |
| 部署文件 | 中央服务 Dockerfile/Compose、Agent 配置示例和 systemd 单元、本地一键启动脚本 |

训练数据保持在原机器硬盘上。平台保存路径和关联元数据；真机部署支持通过 rsync 将选定 checkpoint、归一化参数与推理配置同步到另一台已接入机器，校验通过后由用户单独确认部署。平台不会自动拉取或切换 openpi-umi 代码。

当前平台和 Agent 位于同一仓库、不同目录；openpi-umi 保持独立。训练使用本机 profile 指定的 Python 环境，平台环境不引入 JAX/PyTorch。

## 2026-10-16 ReCap 分阶段配置与自动预检

ReCap 模板已区别于 SFT：用户先选择 `value` 价值函数训练或 `offline_rl` 离线强化学习／ACP，再配置对应配方、项目内训练入口、初始权重以及逐组「数据集／归一化参数／数据处理配置／混采权重」。使用现有 `openpi-sft` 本机环境，阶段切换清空不兼容配置；两阶段分别创建作业，不会自动串联训练、价值推理或优势标注。

价值阶段提供 `val_ratio`（0–0.9）、`eval_interval`（整数 1–1000000）和 `eval_batches`（整数 1–10000），要求 `Pi0ValueConfig` 配方与已含 `value_target` 的数据。默认入口为 `scripts/train_value.py`，多数据集使用 `scripts/train_value_multi_dataset.py`。ACP 阶段提供 `acp_dropout`（0–1），要求读取 `is_positive` 的策略配方、已标注派生数据和初始策略权重，默认单／多数据集入口分别为 `scripts/train.py`／`scripts/train_multi_dataset.py`。入口必须是所选项目内的 Python 文件，满足 `main(config)`／`init_wandb` 接口与阶段匹配规则；已知错误阶段入口、`train_advantage.py` 和混合预处理入口被拒绝。

两阶段强制显式逐数据集／归一化绑定，沿用同机资产、混采权重与 RunInput 占用保护。Agent 自动检查真实 parquet 映射列、监督字段及标签、模型类型、权重加载器；监督值按每组最多 16 个文件、每文件前 64 行有界抽查，价值阶段额外检查入口使用的 JAX 缓存。返回 `recap_stage` 与冻结阶段计划；阶段及其参数同时进入请求、快照、运行环境摘要、PREFLIGHT/START 和任务详情。旧 Agent、缺少字段检查或阶段漂移不能用于提交训练，启动前重新核对；SFT 未指定阶段时保留旧摘要兼容。

这里只开放阶段配置、适配和自动预检入口，不宣称已完成真实 ReCap 训练验收。ACP 使用已登记的标注派生版本，当前适配器不写原始数据，也不自动运行价值／优势标注程序；目标列准备、标注派生版本与血缘、真实价值模型和 ACP 的梯度、指标、checkpoint、取消及恢复仍需逐项验证。当前实现契约见 [ReCap 分阶段训练契约](implementation-contract.md#recap-分阶段训练契约)。
