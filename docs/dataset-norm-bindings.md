# 数据集与 norm_stats 绑定

在“数据与模型”中，数据集可以选择绑定同一机器上已登记且可用的归一化参数（NORM）资产。登记新数据集时可以选择，也可以从已有数据集的“绑定 norm_stats / 修改 norm_stats”操作设置、替换或解除绑定；不绑定也能保存数据集。不会根据名称猜测关联，也不会改写已有训练任务冻结的数据集与归一化配置。

资产目录以数据集为父行，已绑定的 norm_stats 不再独立占用顶层资产行。点击数据集旁的展开按钮，可以查看真实的数据集和归一化参数两项子资产，分别查看详情、选择同步或使用已有管理操作；收起后只保留数据集父行。数据集详情也保留归一化参数的名称、版本、状态、完整路径及修改/解除绑定入口。多个数据集共享一份参数时，每个数据集均可独立展开并引用同一资产，不会合并成以参数命名的集合，也不会复制或删除统计文件。

列表只收纳已被当前权限与归档显示范围内的数据集接纳的同机器 NORM；没有可见关联数据集的参数仍可独立查看。搜索已绑定参数的名称或路径可以找到所属数据集，再展开查看参数；“归一化参数”分类仅列独立参数。分页按数据集父行计数，展开不拆页；子资产可单独选择，跨数据集共享的同一参数 ID 在选择中去重。数据集同步仍可附带已绑定参数。训练和绑定选择器继续使用完整资产集合，列表展示方式不改变现有绑定或训练快照。

也可以在“绑定 norm_stats”中选择“直接填写路径（自动登记）”，输入归一化参数目录或 `norm_stats.json` 文件的本机绝对路径。路径支持所选机器的目录和文件联想，机器离线时仍可手动填写。保存时，控制台在数据集所在机器登记 NORM 资产并绑定；登记新数据集时两份登记也会一起保存。任何一步失败都会回滚，不留下单独的归一化资产登记。

同一机器上已有可用、规范路径相同的 NORM 登记会被复用；重复保存不会反复创建归一化资产。路径会规范冗余斜杠、`.` 和末尾斜杠，不推断目录与其中 `norm_stats.json` 文件的物理等价关系。已有同址登记全部归档或不可用时会提示错误，不自动恢复它们。路径必须在机器的允许访问目录内，不接受根目录、相对路径、`..` 或控制字符。

自动登记仅保存元数据，状态为待校验；它不会读取文件、重命名目录或生成统计参数。训练预检继续检查路径是否存在、文件内容及维度是否兼容。已有训练的配置和正在同步的快照保持原样；同步进行中不能换绑其他归一化资产。

API 中，登记数据集 `POST /api/v1/assets` 或更新绑定 `PUT /api/v1/assets/{asset_id}/norm-binding` 可传 `{ "norm_path": "/data/norm_stats" }`。它与 `norm_asset_id` 互斥；`{ "norm_asset_id": null }` 仍表示解除绑定。客户端不需要先发起独立的 NORM 登记请求。

“同步到其他机器”在数据集已有有效绑定时，默认勾选“一并同步已绑定的 norm_stats”，可以手动取消；没有关联或关联不可用时保持不勾选。单项和批量同步均采用此默认值。提交时会核对用户看到的绑定是否仍然有效，随后将数据集与归一化参数纳入同一个后台同步任务；可在“后台任务”的“数据同步”类型下查看主任务及附带参数的阶段、进度和目标路径。

数据集与附带的 norm_stats 均由源机器直传目标机器，文件内容不经控制台中转；控制台负责调度、校验和进度。目标机器需要能访问源机器的 SSH，且两端具有可用的 rsync。直传条件不满足时显示错误和日志，可在修复后重试；不会切换成控制台中转。

数据集使用用户选择的目标子目录；归一化参数保存到同一父目录下独立的 `norm-stats-<同步任务 ID>` 目录，保持文件名和原始内容。只有两份内容均通过文件完整性校验，平台才会在同一事务中登记目标数据集与目标 NORM，并将目标数据集绑定到目标机器的新 NORM 资产。未勾选时不复制源机器的绑定 ID。

失败、取消或中断会保留该任务拥有的已传文件。重试会复核源资产、绑定、目录和 SSH 身份，复用本任务的部分文件或已校验的发布目录；源绑定发生变化则要求新建任务。不会覆盖无关目录，也不会自动发起重试。

绑定只表达用户选择的资产关系，文件校验只证明传输内容一致；训练使用前仍由预检检查数据字段、维度、处理配置与归一化参数的兼容性。
