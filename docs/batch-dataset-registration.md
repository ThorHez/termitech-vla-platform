# 批量登记数据集

在“数据与模型”点击“批量登记数据集”，选择机器并填写数据集所在父目录。目录支持联想。扫描使用该机器已验证、已保存的 SSH 连接，不依赖 Agent 的在线状态；机器须保持接入，SSH 用户须有目录读取权限，路径须在机器允许的目录范围内。

管理员和操作员均可登记新数据集。操作员可以填写本次新增数据集的特征及初始 norm 绑定，并可使用 `datasets.archive` 删除自己人工登记的数据集登记；删除保留历史关联和物理文件。已有数据集的特征修改、重新绑定 norm 或手动发起校验仍由管理员完成。新登记会自动派生基础校验，仅覆盖本次新增产物。

1. 点击“扫描目录”。默认包含子目录，扫描深度为 1，可调整为 1–8；取消“包含子目录”时只检查父目录及其直接子目录。
2. 在结果中勾选需要登记的数据集，可逐项修改资产名称。相同机器、相同路径的已有数据集会标为已登记并跳过，已删除登记也不会被自动恢复；读取失败的项目不可选择。
3. 在各数据集下分别设置可选的 norm_stats：可选择同机器已有 NORM，或直接填写该数据集的统计量目录或 `norm_stats.json` 路径，保存时自动登记并绑定。每项默认不绑定，选择和路径互相独立；取消勾选会保留输入，但不提交或校验该项。
4. 设置公共资产版本。相同格式的数据集可套用当前账号的数据集格式模板，并检查字段标签、形状和原始动作 horizon；也可先仅登记目录，之后由管理员补录格式。共用归一化参数时，可在公共配置中选择后点击“应用到所选数据集”；只有点击按钮才会覆盖本次勾选项的初始绑定，提交前仍可单独修改。选“不绑定”再应用可统一清除本次勾选项尚未提交的绑定。
5. 点击“登记 N 个数据集”。界面显示新增和跳过数量；登记成功后刷新资产列表。

扫描通过 `meta/info.json` 识别 LeRobot 数据集，可读取有限的任务元信息，展示机器人类型、采样频率、轨迹数量等摘要。发现数据集后停止向其内部继续查找，不读取样本、视频或 Parquet 内容。符号链接和隐藏目录跳过。当前不自动识别其他数据集格式，也不根据维度猜测 Joint/EEF 或绝对量/增量。

每次最多发现 200 个数据集，遍历最多 5,000 个目录、50,000 个目录项，远程扫描约 45 秒截止，元信息总读取上限 8 MiB。达到深度、数量或读取预算时，会明确显示结果可能不完整；可以缩小父目录或分批扫描。预览保留 30 分钟，过期后需重新扫描。批量共用的格式配置不会覆盖原始文件，训练组合仍在新建训练时配置。

登记只保存平台资产信息，新数据集状态为“待校验”，不代表已经通过训练预检。模板由用户明确套用，不会自动改写每个数据集的采样率或任务标签。字段结构不同时界面提示检查并建议分批登记；训练前仍会核验各数据集的真实文件和字段。

每个选中数据集按自己的 norm_stats 选择提交，不会自动推测或共享绑定。批次中的新增数据集与自动登记的 NORM 在同一事务中保存，任一项无效则整批回滚。网络失败后使用同一提交标识重试会返回已保存的结果，避免重复创建；账号、机器连接或允许目录变化后会要求重新确认或扫描。

服务端只为本次人工新增的 DATASET 记录顶层 `registered_by_user_id`。跳过或重放的已有登记不会转移给当前账号；附带 NORM、同步副本、自动产物和历史未记录登记者的资产不因此取得操作员删除权限。

## API

接口需要个人账号及 `datasets.register` 权限，管理员和操作员均具备；写入沿用 CSRF 校验。扫描及提交结果按账号隔离。它不授予 `assets.write`，也不会恢复或覆盖已有数据集。

- `POST /api/v1/nodes/{node_id}/dataset-scans`，正文 `{ "path": "/data/datasets", "recursive": true, "max_depth": 1 }`，返回 202 和扫描标识。
- `GET /api/v1/nodes/{node_id}/dataset-scans/{scan_id}`，轮询 `QUEUED`、`SCANNING`、`READY` 或 `FAILED`，读取候选目录和摘要。
- `POST /api/v1/nodes/{node_id}/dataset-scans/{scan_id}/register`，正文包含 `idempotency_key` 和 `entries`。每项包含 `path`、`name`、`version`，可选原始 `profile` 和 `norm_asset_id` 或 `norm_path`。只接受本次扫描发现且可解析的目录，不能通过该接口登记任意路径。

客户端附带 `X-Dataset-Batch-User`，防止账号切换后继续提交旧账号的表单。正文最多 1 MiB；幂等标识在当前账号内唯一，相同标识提交不同内容返回冲突。扫描过期不影响已成功提交批次的幂等重放。
