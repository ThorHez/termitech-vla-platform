# 训练多指标展示

训练详情的“训练概览 → 训练指标”会自动识别当前执行已上报的数值指标。默认显示 `loss`；没有 `loss` 时显示首个可用指标。勾选多项或点击“全选”可以同时查看多张曲线，每项指标使用自己的纵轴。指标名称支持自定义字段，例如 `grad_norm`、`learning_rate`、`eval/success_rate`。

每个指标显示最近值、该指标自己的上报步数和时间、已载入的有效采样数量。移动指针或聚焦曲线后使用方向键可以查看采样值。学习率等小数值以科学计数法显示，零值和负值保留真实数值。

指标来源为训练进程的 `METRIC` 事件。当前 OpenPI 适配器将 `wandb.log(values, step=step)` 中可转为有限标量的值转换为事件，由 Agent 上报并持久保存。训练代码可一次上报多个字段：

```python
wandb.log({
    "loss": float(loss),
    "grad_norm": float(grad_norm),
    "learning_rate": float(learning_rate),
    "eval/success_rate": float(success_rate),
}, step=step)
```

页面只把有限数值识别为指标，`step`、`total_steps`、`timestamp` 用作进度与时间信息。字符串、布尔值、嵌套对象和图片不绘制为数值曲线。曲线需要有限数值步数；没有步数的有效指标仍可显示最近值。显式上报的空值或无效值会形成断点；未包含某指标的一次上报表示该指标没有新观测。相同步数采用该指标最近一次上报。

稀疏上报的指标使用各自的事件时间，不能把整个 `latest_metrics` 字典的更新时间当成每个指标的采样时间。仅从最新快照得到数值、尚未载入对应事件时，页面明确标记该指标步数与时间未知。

当前事件订阅最多保留最近 5,000 条已载入训练事件（包含其他事件类型），曲线及采样数量反映当前载入范围。达到上限时显示历史范围提示。服务端历史事件仍保留；此功能未增加全量历史聚合接口，也不将不同执行尝试的指标拼成一条曲线。
