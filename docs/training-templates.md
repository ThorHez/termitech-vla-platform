# 训练模板

在「新建训练」中的「训练模板」保存常用配置。同一账号可以保存多套模板，登录同一控制台后，可跨浏览器、跨设备使用。新模板默认为个人可见，也可以共享给工作区。

## 保存与套用

1. 在训练向导中配置机器、运行环境、基础模型、数据处理方式和训练参数；未填写完也可以保存。
2. 填写模板名称和说明，点击「保存模板」。同一账号下，名称相同会覆盖已有模板并递增版本号；新名称保存为另一套模板。名称会去掉首尾空格，不同账号的同名模板相互独立。保存模板不会启动训练，也不会修改训练项目源码。
3. 下次新建训练时选择模板，点击「套用模板」。平台读取该模板的最新版本，回到第一步，并将配置保存为当前草稿。
4. 选择本次训练的数据集，已绑定的有效 `norm_stats` 会自动带出，也可手动更换。核对处理方式、参数和训练名称，再继续预检。

模板会保留机器、运行环境、基础模型、训练方式、训练参数，以及每组数据的处理器、字段组合和混采权重。**保存和套用时都会清空数据集与归一化资产选择**。选择新数据集后，平台优先使用该数据集当前绑定的归一化资产，不会沿用模板上一次的数据或覆盖之后的手动改选；已有模板也适用，无需重新保存。失效、跨机器或类型错误的绑定不会自动选用。多数据集未选择共享参数时，仅带出当前组的绑定；已经选定的共享参数会保留。

套用时会检查已有资源：离线机器保留选择并提示；已移除的机器、不可用或不兼容的环境、不可用或不属于该机器的模型会清空并提示重新选择。平台不会自动换成其他资源。所选新数据仍须与保留的处理配置兼容，最终由本次预检核对。

每个训练入口（SFT、ReCap、norm_stats、链路测试等）都有独立草稿。打开模板卡片时只恢复该入口的草稿；首次使用从空白配置开始。切换训练方式会保存原草稿，再恢复目标入口的草稿。

ReCap 模板在每种模式内还按阶段保存草稿。切换阶段会恢复该阶段的数据、权重和参数。提交前在当前阶段完成预检并确认配置。

套用已保存的模板会替换当前账号在对应训练入口的草稿，并回到第一步。跨训练方式套用时，原入口草稿会先保存。需要保留目标入口的配置时，先另存个人模板。若另一设备已更新目标草稿，平台会提示处理草稿冲突，防止直接覆盖新内容。

### ReCap 回报价值流程

打开 ReCap 模板后，在向导顶部选择「ReCap 模式」，依次配置 Value 训练、优势值标注和 ACP 训练。点击任一阶段即可编辑该阶段的配置，每个阶段单独预检和提交。已有包含 `is_positive` 的数据时，两种模式均可直接配置 ACP。

1. **Value 训练**。在「数据与权重」中绑定带 `value_target` 的 LeRobot 数据、对应归一化统计和 PyTorch 初始权重。设置训练参数，预检并确认生成的配置后启动。作业输出价值模型检查点。
2. **优势值标注**。在「标注数据配置」中选择同机已完成 Value 训练的检查点、待标注数据、归一化统计和标注参数，预检确认后提交。可从 Value 作业详情带入所选数据行和检查点。每个标注作业处理一组数据，完成后登记含 `is_positive` 的派生数据。
3. **ACP 训练**。可从标注作业详情带入派生数据和来源归一化参数，选择初始 **JAX / Orbax 动作策略**权重，设置训练参数，预检并确认生成的配置后启动。

```bash
uv run python scripts/acp/lerobot_value_infer_pytorch.py \
  --config-file /path/to/run/training_config.py \
  --checkpoint-dir /path/to/value/checkpoint_step \
  --dataset-root /path/to/lerobot_with_value_target \
  --output-dir /path/to/derived_dataset
```

在训练机上手动标注时，多数据集配方可用 `--dataset-index` 选择与目标数据匹配的处理配置。

### Stage Advantage

Kai0 的阶段优势估计方法称为 [Stage Advantage](https://arxiv.org/html/2602.09021#S3.SS4)。Kai0 官方仓库的策略训练步骤称为 [AWBC（Advantage-Weighted Behavior Cloning）](https://github.com/OpenDriveLab/kai0/blob/main/stage_advantage/awbc/README.md)。平台使用 Stage Advantage 生成含 `is_positive` 的数据，再交给共用的 ACP 策略训练入口。

1. **阶段进度训练**。绑定一组 LeRobot 数据和归一化统计，选择 PyTorch π0.5 初始权重，并填写必填的「阶段进度列」，例如 `stage_progress_gt` 或 `episode.progress`。该列须在 Parquet 中存在，并在 `meta/info.json` 的 `features` 中声明为数值标量，取值在 `[0, 1]`。以两阶段为例，在每条轨迹中标记分界，把两段的逐帧进度分别线性映射到 `[0, 0.5]` 和 `[0.5, 1]`。预检通过后启动训练。训练完成后登记进度模型检查点，可以先查看训练指标，再选择检查点作为初始权重开启新的训练作业。
2. **优势标注**。只可选择当前机器上已成功完成的阶段进度训练作业产出的可用检查点。从训练作业详情进入时会带入所选检查点、数据、归一化和字段映射。配置优势窗口、阶段数及每阶段正例比例，预检后单独提交标注。作业完成后登记带 `is_positive` 的派生数据集。
3. **ACP 训练**。在标注作业详情点「用此数据配置 ACP」，选择初始 **JAX / Orbax 动作策略**权重，预检后启动。

Value 和阶段进度训练使用 `scripts/acp/train_recap_pytorch.py`，选择登记为「PyTorch / Safetensors」的估计器或骨干权重。阶段优势标注使用 `scripts/acp/lerobot_stage_progress_infer_pytorch.py`。两种模式的 ACP 均使用 JAX，单数据集运行 `scripts/train.py`，混采运行 `scripts/train_multi_dataset.py`，生成 Orbax 策略检查点。已有手工登记的模型可在详情里补录权重格式。具体数据与产物契约见 [ReCap 分阶段训练契约](implementation-contract.md#recap-分阶段训练契约)。

## 共享到工作区

选中自己的模板，点击「共享到工作区」并确认。有训练权限的工作区成员可以查看模板的名称、说明和配置，再将它套用到各自的训练草稿。成员套用后，可以清除模板选择并将当前训练配置另存为个人模板。

所有者可以更新、删除或取消共享。更新共享模板会让成员在下次套用时读取新版。取消共享后，模板恢复为个人可见，已经套用的配置保存在各自的训练草稿。旧模板如提示配置格式不兼容，请从训练向导重新保存后共享。

## 更新与删除

修改向导配置后，在「训练模板」中填写自己已有的模板名称，点击「保存模板」或「更新共享模板」，即可用**当前向导配置**覆盖同名模板。也可以先选中自己的模板，保留其名称后保存。若改为新名称，则另存一套模板，原模板保留。单纯编辑向导不会自动更新模板。

点击「删除」后，需在页面内再次确认。更新与删除都检查所选版本：如果其他页面或设备已修改模板，操作会报版本冲突；请刷新模板列表、核对最新版本后再操作。删除模板不删除已经创建的训练任务。

## 模板与草稿的区别

| 项目 | 训练模板 | 训练草稿 |
| --- | --- | --- |
| 用途 | 保存多套可重复使用的配置 | 每个训练入口独立继续尚未完成的配置 |
| 保存方式 | 显式保存、更新或删除 | 编辑时自动保存，显示同步状态 |
| 数据集与归一化选择 | 清空；选择新数据集后自动带出有效绑定，可手动更换 | 保留当前填写的选择 |
| 套用行为 | 替换所属训练入口的草稿，回到第一步 | 仅恢复当前训练入口的填写内容 |

模板按账号保存在服务端，草稿进一步按训练入口隔离，清空或创建训练后的清理只影响当前入口。旧版单份草稿仅恢复到它原本所属的入口。模板不包含可复用的预检结果或启动授权；套用后必须重新「生成 config 并预检」，核对生成的 config 并确认，才能提交训练。资源、代码或配置变化时仍以新的预检结果为准。
