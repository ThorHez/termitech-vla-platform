# 个人训练模板

在「新建训练」中的「我的训练模板」保存常用配置。同一账号可以保存多套模板，登录同一控制台后，可跨浏览器、跨设备使用；其他账号看不到这些模板。

## 保存与套用

1. 在训练向导中配置机器、运行环境、基础模型、数据处理方式和训练参数；未填写完也可以保存。
2. 填写模板名称和说明，点击「保存模板」。同一账号下，名称相同会覆盖已有模板并递增版本号；新名称保存为另一套模板。名称会去掉首尾空格，不同账号的同名模板相互独立。保存模板不会启动训练，也不会修改训练项目源码。
3. 下次新建训练时选择模板，点击「套用模板」。平台读取该模板的最新版本，回到第一步，并将配置保存为当前草稿。
4. 选择本次训练的数据集及各自的归一化参数，核对处理方式、参数和训练名称，再继续预检。

模板会保留机器、运行环境、基础模型、训练方式、训练参数，以及每组数据的处理器、字段组合和混采权重。**保存和套用时都会清空数据集与归一化资产选择**，每次训练需重新选择；不会因套用模板自动沿用上一次的数据。

套用时会检查已有资源：离线机器保留选择并提示；已移除的机器、不可用或不兼容的环境、不可用或不属于该机器的模型会清空并提示重新选择。平台不会自动换成其他资源。所选新数据仍须与保留的处理配置兼容，最终由本次预检核对。

套用会替换当前向导草稿，需要保留当前配置时先另存模板。若另一设备已更新草稿，平台会提示处理草稿冲突，防止直接覆盖新内容。

## 更新与删除

修改向导配置后，在「我的训练模板」中填写已有的模板名称，点击「保存模板」，即可用**当前向导配置**覆盖同名模板。也可以先选中已有模板，保留其名称后保存。若改为新名称，则另存一套模板，原模板保留。单纯编辑向导不会自动更新模板。

点击「删除」后，需在页面内再次确认。更新与删除都检查所选版本：如果其他页面或设备已修改模板，操作会报版本冲突；请刷新模板列表、核对最新版本后再操作。删除模板不删除已经创建的训练任务。

## 模板与草稿的区别

| 项目 | 训练模板 | 训练草稿 |
| --- | --- | --- |
| 用途 | 保存多套可重复使用的配置 | 继续一次尚未完成的训练配置 |
| 保存方式 | 显式保存、更新或删除 | 编辑时自动保存，显示同步状态 |
| 数据集与归一化选择 | 清空，每次重新选择 | 保留当前填写的选择 |
| 套用行为 | 替换当前草稿，回到第一步 | 恢复尚未完成的填写内容 |

模板和草稿都按账号保存在服务端。模板不包含可复用的预检结果或启动授权；套用后必须重新「生成 config 并预检」，核对生成的 config 并确认，才能提交训练。资源、代码或配置变化时仍以新的预检结果为准。
