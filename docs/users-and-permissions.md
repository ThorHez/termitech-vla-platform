# 用户与权限

网页使用独立账号登录，不开放注册。用户、会话及审计记录保存于中台数据库，原节点、资产、配方和训练记录无需重建。当前为一个共享工作空间：业务记录及日志可以互相查看，写操作同时核对角色和任务创建者。尚未提供项目或团队之间的数据可见性隔离。未完成的训练配置草稿、个人训练模板和数据集格式模板按账号保存。

| 能力 | 管理员 admin | 操作员 operator | 只读 viewer |
| --- | --- | --- | --- |
| 查看机器、公共资产、任务、日志、部署和已保存配方 | 是 | 是 | 是 |
| 预检并创建自己的训练、同步和推理部署任务 | 是 | 是 | 否 |
| 取消、恢复、重试、删除训练记录；启停、测试和删除部署；重试、取消和删除同步记录 | 全部任务 | 仅自己创建的任务 | 否 |
| 保存、恢复和清空自己的训练草稿及个人训练模板 | 是 | 是 | 否 |
| 保存、使用和删除自己的数据集格式模板 | 是 | 是 | 否 |
| 使用公共资产和已保存配方，查询受管目录、机器配方及处理器 | 是 | 是 | 只查看已保存信息，不触发机器查询 |
| 单个或批量登记数据集，填写新数据集特征和初始 norm 绑定 | 是 | 是 | 否 |
| 删除资产登记（归档登记，保留物理文件） | 全部资产 | 仅自己人工登记的数据集 | 否 |
| 单独登记模型或 NORM、修改已有公共资产特征和 norm 绑定、手动发起公共数据校验 | 是 | 否 | 否 |
| 创建或修订公共配方，回写训练仓库 config 并创建 commit | 是 | 否 | 否 |
| SSH 连接、安装/升级/卸载 Agent、断开机器、修改环境和受管目录 | 是 | 否 | 否 |
| 创建用户、修改角色、禁用、重置密码、查看审计 | 是 | 否 | 否 |
| 修改自己的密码、退出自己的会话 | 是 | 是 | 是 |

操作员可以把共享训练的配置复制到一项**新的个人训练任务**，也可以选用共享模型产出创建自己的部署；这不会取得原任务的控制权。已有部署准备记录、同步任务和推理服务仍由原创建者管理。管理员可以处理所有账号的任务；缺少创建者的历史记录只允许管理员操作，不会自动分配给后来登录的人。

任务创建者与执行发起者分别记录。`owner_user_id` 表示原创建者，决定普通成员可以管理哪项任务；管理员为已有同步任务重试或为已有推理服务启动新一轮执行时，`execution_user_id` 记录实际发起这次执行的管理员，原创建者保持不变。GPU 预留和本次执行准入使用当前执行发起者的账号与权限；管理员不能因此借用原创建者的个人预留卡。复制训练配置创建新训练则产生新的任务和创建者。

资产和保存配方是共享资源，已有公共资产的特征和配方由管理员统一维护。操作员具备 `datasets.register` 权限，可单个或批量登记新的数据集，在提交时填写数据集特征、套用自己的格式模板，并选择初始 norm 资产或路径；填写 norm 路径时可在同一事务中附带登记 NORM。新登记会派生基础校验，权限仅覆盖本次登记的精确产物。操作员另具备 `datasets.archive`，可删除自己人工登记的数据集登记；已有数据集的特征修改、norm 重绑和手动重新校验仍需要管理员的 `assets.write` 权限。只读账号也可查看已登记数据集的实时统计，读取范围固定为已登记路径及归一化绑定。操作员保存个人草稿、个人训练模板或格式模板不会修改公共资产和公共配方，也不会回写训练仓库。同步由操作员创建自己的后台任务，成功后目标资产加入共享目录；只有自己的同步记录可取消、重试或删除。删除任务记录保留已登记产出与机器文件；删除资产登记不删除物理文件。

数据集的人工登记者由服务端顶层 `registered_by_user_id` 记录，只在单个或批量人工新登记时赋值。操作员不能删除别人登记、历史未记录登记者或同步/自动任务产出的数据集，也不能删除模型和 NORM；这些由管理员处理。批量跳过已有数据集或重放提交不会把登记者改为当前账号，客户端 metadata 中的同名字段不构成权限依据。删除确认绑定打开时的账号，切换账号会丢弃旧弹窗和迟到回调。

操作员也可使用训练权限（`training.write`）提交归一化统计任务。成功后，系统按该任务冻结的源数据集 ID 登记统计产物，并自动绑定到对应源数据集；重新统计可以更新提交时的默认绑定，计算期间已被修改的绑定则保留用户选择。这是已受理统计任务的派生发布例外，详见[归一化统计](shared-normalization.md)。它不授予操作员单独登记模型或 NORM、任意替换或解除已有公共 norm 绑定的权限，这些编辑仍仅允许管理员执行。

后端独立检查每次请求的角色、任务创建者和关联记录，直接调用 API 同样受约束。新增但未登记权限的接口默认拒绝。页面显示任务创建者；跨账号切换会清除业务缓存、拒绝迟到响应并停止原账号的后续异步操作。训练提交成功后，草稿清理期间切换账号或关闭向导，也不会再由旧窗口跳转新账号的页面；同一会话的普通草稿清理失败不影响查看已创建的训练。配方写回恢复记录按账号保存，旧版没有账号归属的浏览器恢复记录不会自动沿用。

## 个人数据集格式模板

管理员和操作员均可从「数据与模型」右上角进入「我的格式模板」，独立查看、删除自己的模板。选择模板后点击「载入个人草稿」，会把完整格式载入当前窗口的个人草稿；可以检查或修改机器人、视觉和状态/动作标签，使用原名称保存更新，或换一个名称另存副本。也可从空白个人草稿新建格式模板。

个人草稿窗口不会登记、修改或绑定公共数据集。管理员和操作员都可在新数据集登记表单中套用自己的格式模板；维护已有公共数据特征仍仅允许管理员。个人模板权限不替代 `datasets.register`、`datasets.archive` 或 `assets.write`。未保存的个人格式草稿在关闭窗口后丢弃，已保存模板按账号持久保留；切换账号会清除当前窗口内容并重新读取新账号的模板。

## 训练配置草稿

每个账号的每个训练模板独立保存一份未完成的草稿，SFT、ReCap、norm_stats、链路测试等入口互不共用。通用「新建训练」默认打开 SFT 草稿；从模板卡片进入时恢复该模板的草稿，没有草稿时从空白开始。切换训练方式会先保存原模板，再读取目标模板的草稿，不自动搬用机器、数据或参数。旧版单份草稿仅归入它原本记录的训练模板。

新建训练表单会自动保存机器、资产绑定、处理器与组件组合、模型、训练参数和配方编辑内容；重新打开、刷新页面或换浏览器、设备登录同一账号后，可以继续填写。页面显示同步状态，也提供「立即保存草稿」和「清空当前模板草稿」。关闭弹窗会先尝试保存；未同步的修改临时保存在当前浏览器中，并按账号和训练模板分开。

服务端仅使用当前登录身份读写草稿，客户端不能指定其他所有者。多设备同时编辑同一模板采用独立的版本检查，旧版本不会自动覆盖新内容；冲突时由用户明确选择加载服务端草稿或保留当前填写。清空只移除当前模板的草稿，并保留递增的版本记录，防止迟到的自动保存恢复旧内容。

草稿允许未填写完整的配置，最多恢复到「训练方式与参数」页面。预检结果、启动确认、执行标识和登录凭据不会保存，恢复后仍需重新预检并确认本次 config。配方修改仅恢复编辑文本，重新读取并核对来源代码后才会显示；不会因恢复草稿自动写入 config 或提交 Git。成功创建训练后只清理本次训练模板的草稿，多设备上较新的草稿不会被旧窗口清理。

## 创建首次管理员

先备份数据库。在服务停止的情况下，使用中台自己的 Python 和**目标中台的数据库**运行：

```sh
cd /data4/termitech-vla-platform
.venv/bin/python -m vla_control.users create-admin \
  --database-url sqlite:////data4/termitech-vla-platform/.local/control.db \
  --username admin
```

命令交互输入并确认密码，不把密码放入命令参数、日志或网页。首次管理员没有内置密码。不要操作迁移前本机数据库来创建生产账号，也不要为验证用户功能而启动使用旧数据库的第二个中台。

管理员登录后进入「用户与权限」管理账号。管理员创建账号或重置密码后，用户必须先改密码才能访问业务页面。密码最少 12 字符，最多 256 字符；支持粘贴。忘记最后一个管理员密码时，拥有服务器控制台权限的人可使用离线重置命令，参见 `python -m vla_control.users --help`。

禁用用户、修改角色、重置密码会立即使其旧会话失效；自己改密码也会撤销其他会话并轮换当前会话。系统拒绝禁用或降级最后一个可用管理员。
同一浏览器的其他标签页在登录、退出或改密后立即清除旧身份与页面缓存，再验证当前账号；跨标签页通知不传递凭据。

禁用账号或撤销训练权限会暂停该账号尚未开始的排队执行，并在首次向 Agent 投递启动命令前再次核对权限。页面分别显示“执行账号已停用”或“训练权限已撤销”，由管理员处理；空闲 GPU 预留会释放。已经投递的启动命令、已启动的进程和已有资源占用保留，不会因网页账号被禁用而自动终止；管理员仍可明确取消、停止或处理异常。命令的 `delivered_at` 保存首次投递事实，已投递命令允许按原执行标识重传。旧库升级时保留已有在途命令的重传语义，不把迁移前可能已投递的命令误当成从未投递。

存储目录修改、训练环境新增与切换、配方写回、单次推理测试、机器查询和公共数据校验都会保存命令的实际发起者与所需权限。机器查询包括受管路径、配方及推理配置联想、配方详情、数据处理器和数据集字段读取。提交事务会重新验证原会话，敏感操作同时重新验证近期密码确认；首次下发前再次核对发起账户是否仍启用并具备相应权限。管理员代他人发起测试后被降为操作员，也不能继续执行该跨用户测试。被拒绝的测试只标记本次测试失败，已有推理服务保持运行。

查询缓存复用保留原命令发起者；尚未下发的原命令失权时，会拒绝该命令并允许当前有权限的账号新建查询。普通配方和推理配置查询分别记录查询权限与训练权限。公共数据校验失权后会同步显示失败，管理员可重新提交；旧回执不能恢复已拒绝的命令或覆盖新校验结果。已经下发的查询与校验保留重传及回执处理。

操作员成功同步数据集后，系统仍会自动校验该次同步的新产物。此派生校验绑定同步执行发起者、原同步任务及精确的目标资产，只允许校验该任务实际登记的产物，并在首次下发前复查账号及任务归属。它不会授予操作员手动发起其他公共资产校验的权限。

生成 Agent 配置会在返回登记凭据前重新核对原会话、机器管理权限及近期密码确认；机器重命名也会在写入事务内核对原会话和机器管理权限。修改显示名称继续沿用无需重复验密的规则。

尚未首次下发、又无法确认发起者的历史管理命令不会被新登录的管理员自动认领，需要重新提交。配方写回只在明确从未下发且因授权检查拒绝时允许创建新命令；已经下发或可能存在 Git 提交回执的请求继续复用原操作，避免重复提交。

远程安装、升级和卸载保存发起账号，在工作线程接手及开始安装或卸载前复核机器管理权限。被撤权且尚未执行的操作转为可重试的中断状态，不移除已有 Agent 身份或凭据；已经开始执行的安装流程和既有连接不会因浏览器会话到期被中断。

重新检查已有 SSH 连接只可复用仍有效的原凭据，不能恢复已撤销、过期或已删除的凭据。需要重新连接时，管理员须重新输入 SSH 密码创建新连接，并通过当次会话、机器管理权限及近期密码确认的准入检查；旧连接 ID 或迟到的检查结果不能恢复原连接的授权。

批量扫描与资产登记把原请求会话传入后台写入事务，等待请求正文或工作线程期间发生的退出、禁用、降权及会话过期都会阻止新写入。退出登录与业务提交使用相同的账号事务锁，明确二者的先后次序。已经受理的后台任务无需网页持续登录；账号撤权与普通网页会话到期分别处理。

权重导出尚未下发便被撤权时，后台同步会及时转为中断并释放同步工作槽；已经下发或已开始的导出保留原回执和取消流程。


## 会话与部署

- 会话默认登录后最多 8 小时有效；连续 1 小时没有鼠标、键盘、触摸或滚动操作即过期。服务端同时检查两个截止时间，后台状态轮询、日志刷新和读取账号信息都不延长空闲时间。活动标签页通过受 CSRF 保护的活动请求更新空闲时间，其他标签页重新向服务端读取截止时间，活动不会延长登录后 8 小时的绝对期限。
- 创建和修改用户、重置密码、SSH 连接和部署、断开机器、卸载 Agent、生成 Agent 配置、回写训练 config 前，需要再次输入当前账号密码。验证通过后 5 分钟内可继续这些操作；再次验证不会延长登录或空闲截止时间。普通训练和资源查询不需要重复验证密码。
- 网页会话过期只撤销管理访问，不停止 Agent、训练或后台调度。再次登录后可继续查看任务。服务端保存随机会话凭据的哈希，网页不在浏览器存储共享管理员令牌。
- Cookie 为 HttpOnly、SameSite=Strict，默认 Secure。写请求需要绑定当前会话的 CSRF 请求头，并校验浏览器请求来源。HTTPS 代理应保留正确的 Host 和协议，避免把任意客户端提供的转发头当作可信来源。
- 密码使用带随机盐的 scrypt 哈希；登录和敏感操作密码验证失败均限速。代理部署的来源地址识别必须与可信代理配置一起验收，不能依赖开放的 X-Forwarded-For。
- 用户管理、密码和登录事件及管理写请求记录审计。审计不保存密码、请求正文、查询串、SSH 凭据或 Agent 令牌。审计仍存于本数据库，不是防篡改的外部审计系统。

配置示例：

```text
VLA_LEGACY_ADMIN_ENABLED=false
VLA_SESSION_COOKIE_SECURE=true
VLA_SESSION_TTL_SECONDS=28800
VLA_SESSION_IDLE_SECONDS=3600
VLA_SESSION_REAUTH_SECONDS=300
VLA_HOST=127.0.0.1
```

仅对本机 HTTP 开发或经 SSH 转发的本机测试，可显式设置 `VLA_SESSION_COOKIE_SECURE=false`；公网入口保留默认值并按 [HTTPS 配置](https.md)设置反向代理、公开来源及可信代理。`VLA_ADMIN_TOKEN` 不再是网页登录凭据。旧协议回归测试可以显式开启临时兼容模式，但只要数据库中存在用户，旧令牌就会失效。生产环境不得开启此兼容模式。

关闭旧认证兼容模式后，即使数据库中尚无用户，旧的无账号任务也不能再凭旧模式授权首次下发执行、管理或查询命令，尚未接手执行的后台工作线程同样不能开始执行。已经下发的命令继续保留原执行标识的重传语义，已开始的任务和进程不会因关闭兼容模式而自动停止；状态查询和明确停止等生命周期处理仍保留。

Agent 继续使用独立登记令牌及每节点令牌。人类会话不能认证 Agent 协议，节点令牌不能登录网页，也不需要重新登记机器。

升级旧版本数据库时，服务会添加会话安全字段并撤销缺少这些字段的旧网页会话，所有人需要重新登录；账号、密码、Agent 凭据和业务记录保留。修改已有部署的环境文件时，应同时核对上面三个时间设置，显式环境配置优先于默认值；修改后重启中台服务。原先签发的短期会话和 Cookie 不会自动延长，重新登录后采用新期限。

操作员属于受信任的训练执行者：提交训练会使用登记的项目代码、解释器和 Agent 系统账户权限。若 Agent 以 root 运行，训练进程也具有该账户的权限；本模块没有提供进程或文件系统沙箱。仅给可信成员分配操作员角色。

## 当前发布边界
