# 数据集图像处理

数据集登记的每个视觉输入可在 `image_processing.resize_mode` 中保存尺寸处理方式。训练增强按训练模板的相机设置执行。训练读取本次冻结的资产描述和训练配置，不修改原始数据文件。

## 登记与编辑

单个登记自动通过所属机器读取 `meta/info.json`，使用已完成的 `DATASET_INSPECT` 记录作为源形状证据。批量登记使用本次扫描返回的字段形状。客户端不能自行提交或覆盖服务端的 `_image_registration` 证据。

任何非 224×224 的图像必须为对应的真实相机字段明确选择处理方式；未读取元信息、字段缺失、未选择或不支持的策略会阻止登记。已读取但形状无法明确推断的字段不会被当作 224×224，仍需显式配置；实际布局由训练的数据处理配置确认。新登记若包含数据集特征，API 同样要求可信的读取记录。历史无特征的路径登记接口保留兼容，但训练遇到非 224×224 图像且缺少处理策略时会拒绝，提示补全数据集特征。

可以在已有数据集的特征编辑窗口补齐策略。策略跟随个人格式模板保存；套用缺少图像策略的旧模板时，保留当前相同字段、相同图像类型的明确选择，不会从其他相机借用策略。

尺寸处理在“数据与模型 → 编辑数据特征 → 视觉输入”设置。单个登记、批量登记的公共特征和个人数据集格式模板使用同一表单。已确认是 224×224 的图像可以省略尺寸处理。

在“新建训练 → 数据集 → 组件组合 → 组合视觉输入”中为每路相机选择“训练图像增强”，再用“我的训练模板”保存。增强随该组数据的处理配置保存，套用模板时保留。显式选择“OpenPI 默认增强”会使用模型默认规则。旧训练配置若省略相机增强字段，仍兼容旧资产中登记的增强值。

## 处理选项

| `resize_mode` | 行为 |
| --- | --- |
| `pad` | 等比缩放并居中补黑边到 224×224 |
| `center_crop` | 按目标比例居中取景并缩放到 224×224 |
| `stretch` | 直接拉伸到 224×224 |

| `augmentation` | 训练行为 |
| --- | --- |
| `default` | 保持 OpenPI 默认：非 wrist 视角使用裁剪、旋转、颜色扰动，wrist 视角使用颜色扰动 |
| `none` | 关闭该视角的训练增强 |
| `color` | 仅颜色扰动：brightness=0.3、contrast=0.4、saturation=0.5 |
| `crop_rotate_color` | 随机裁剪到边长的 95%，恢复原尺寸，±5°旋转，再进行上述颜色扰动 |

默认增强根据处理器产生的模型视角名判断 wrist，不根据资产中的中文视角名称判断。深度图只接受 `default` 或 `none`，不执行 RGB 随机增强。

复现 Helios 时，三路资产图像均选择 `pad`。训练模板中头部选择 `crop_rotate_color`，左右腕部选择 `color`。

## 训练与兼容

尺寸变换先作用于数据源图像，再进入模型的标准 224×224 处理；已经满足尺寸的标准 ResizeImages 不会再次改变画面。图像增强在模型预处理阶段按样本、按视角执行一次，混采数据集可使用不同策略。视频帧继承所属样本的策略，保留有效帧和相机掩码。

组合处理器使用明确的源字段和模型视角映射。独立处理器在所有源 RGB 相机的增强选择一致时可统一路由；未登记的 224×224 相机仍保留默认增强。若不同相机选用不同增强，必须能从处理器证明相机映射，否则预检拒绝并提示使用显式组合处理。不会根据图像内容猜测来源。会预先展开历史帧的旧独立视频处理器暂不接受此策略，预检会明确拒绝，避免原始字段与实际历史帧不一致。数值 RGB/深度图需由同字段、同类型的显式组合配置建立布局，深度图还需真实深度语义。

模型导出保留同一空间处理策略，推理执行相同的缩放、裁剪或补边，不执行训练随机增强。无法证明推理字段映射的旧处理器会明确拒绝导出，不会悄然回退默认补边。

训练模板中的显式增强选项需要支持 `composition.cameras[].augmentation` 的 OpenPI 组合处理解析器。关闭或指定增强还需要模型支持 `IMAGE_AUGMENTATION_POLICY_VERSION=1`。控制台、Agent 和 OpenPI 训练环境应一同更新。

资产尺寸策略和训练增强设置分别随资产特征与训练配置冻结到运行记录，并进入预检计划与证据摘要。修改训练增强需要重新预检，可复用有效的基础数据校验。提交和启动不额外解码样本或扫描时间戳。`norm_stats` 任务只读取状态和动作数值列，不执行图像处理或增强。
