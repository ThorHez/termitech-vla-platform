# 数据集格式模板

管理员和操作员可以保存数据集格式模板，在登记同格式的数据集时直接套用。模板默认仅创建者可见，创建者可以将其共享给工作区内其他管理员和操作员。模板保存在控制台数据库，同账号可跨浏览器和设备使用。

## 管理和共享模板

在「数据与模型」右上角点击「数据集格式模板」。该入口对管理员和操作员开放。

1. 选择个人或共享模板，点击「载入个人草稿」。可编辑机器人、相机、状态与动作标签、形状、采样频率和任务描述。
2. 用自己的模板名称保存可更新原模板，用新名称保存可创建个人副本。载入其他账号的共享模板后，填写名称即可保存个人副本。
3. 选择自己的模板，点击「共享到工作区」。工作区内其他管理员和操作员可以套用该模板。共享状态下，保存同名模板会更新工作区所见的格式。
4. 选择自己的共享模板，点击「取消共享」即可收回模板访问。创建者也可删除自己的模板。已经套用到草稿或登记表单中的格式是独立副本。

未保存的个人草稿仅保留在当前窗口，关闭后丢弃。切换账号会清空窗口并按新账号重新读取。应用到已有公共数据集的特征编辑需要管理员权限。

## 从已有数据集创建

1. 打开“数据与模型”，点击已配置的数据集名称。
2. 在详情中点击“保存为格式模板”，填写便于辨认的模板名称后保存。
3. 管理员也可在“数据集特征”编辑窗口保存当前格式，无需修改已有资产。

同一账号保存同名模板会更新自己的模板。不同账号可使用相同名称，模板列表会标注其共享状态。

## 登记后续数据集

单个新数据集登记需要 `assets.register`，批量数据集登记需要 `datasets.register`，已有公共资产的特征编辑需要管理员的 `assets.write`。删除自己人工登记的数据集、模型或归一化资产另需 `assets.archive`。

1. 点击“登记资产”，选择数据集并填写当前资产的名称、机器和路径。
2. 在数据集配置区选择个人或共享格式模板，点击“套用模板”。
3. 检查任务描述等默认值，按当前数据集修改；选择其归一化参数绑定后登记。

模板复用机器人类型、机械臂配置、数据格式、相机名称和字段、状态与动作字段标签、字段形状、数据已有的动作 horizon、采样频率和任务描述等登记信息。模板不保存资产名称、机器、路径、版本、归一化资产 ID、字段组合处理方案或训练参数。

如果原始字段已经拼接了多个分量，可将字段“表示”选为“组合向量（多分量）”。例如，一个 `actions` 字段同时包含位置、旋转和夹爪开度。此时“分量”固定为组合向量，字段的原始形状和 horizon 保留。这个标签不声明字段已经归一化，也不说明内部坐标顺序；训练时仍需配置目标表示、动作分块和归一化规则。组合状态字段按完整宽度使用，动作分块总宽度必须与原始字段一致。

控制台和 Agent 都需要包含该标签的校验支持；旧版 Agent 需更新后再使用新标签预检。原生 OpenPI 继续读取明确的训练组合配置，训练目标表示仍为 EEF 或 Joint。

应用模板只修改当前表单中的格式配置，不修改模板来源数据集，也不会批量改写已登记的资产。应用值视为用户明确选择，数据读取推断不会自动覆盖这些值；仍可手工编辑，训练预检继续验证实际文件。数据中已有的动作 horizon 与新建训练中的模型动作预测长度继续独立配置。

模板列表中可以删除不再使用的模板。删除模板不影响已登记的数据集、历史训练或机器上的文件。模板保存或读取失败时仍可手工填写和登记。

## API

接口需要个人账号及 `dataset-templates.write` 权限。写操作使用现有 CSRF 校验。

- `GET /api/v1/dataset-format-templates` 列出当前账号自己的模板和工作区共享模板，返回 `shared`、`is_owner` 等摘要字段。
- `POST /api/v1/dataset-format-templates` 以 `{ "name": "…", "profile": { … } }` 按名称新建或更新自己的模板。新模板默认私有，更新沿用现有共享状态。
- `GET /api/v1/dataset-format-templates/{template_id}` 读取可访问模板的完整格式。
- `PUT /api/v1/dataset-format-templates/{template_id}` 带 `expected_revision` 更新自己的模板。
- `PUT /api/v1/dataset-format-templates/{template_id}/sharing` 由创建者提交 `{ "expected_revision": 1, "shared": true }` 共享模板，或提交 `shared: false` 取消共享。共享状态变更时递增模板版本。
- `DELETE /api/v1/dataset-format-templates/{template_id}` 带 `expected_revision` 删除自己的模板。

其他账号的私有模板无法读取，跨账号修改、删除及更改共享状态均返回 404。客户端附带 `X-Dataset-Template-User`，服务端据此校验登录账号。每个账号最多保存 100 个模板，请求最多 64 KiB。模板版本冲突时需重新读取。
