# 数据集格式模板

管理员和操作员均可把已有公共数据集的格式信息保存为个人模板，并在登记新的同格式数据集时直接套用。登记需要 `datasets.register` 权限；删除自己人工登记的数据集另需 `datasets.archive`，模板本身不授予资产删除或已有数据集编辑权限。模板保存在控制台数据库，按账号隔离，同账号可跨浏览器和设备使用。

## 管理和复用个人模板

在「数据与模型」右上角点击「我的格式模板」。该入口对管理员和操作员开放，无需公共资产编辑权限；只读用户不显示入口。

1. 从列表选择自己的模板，点击「载入个人草稿」查看完整格式。
2. 下方个人草稿可修改机器人、相机、状态/动作标签、形状、采样频率和任务描述；载入和编辑均不会提交公共资产变更。
3. 保留原名称保存可更新自己的模板，填写新名称保存可创建副本；也可从空白草稿新建。
4. 删除模板时选择目标后点击删除，并确认模板名称。模板仍只对当前账号可见。

未保存的个人草稿仅保留在当前窗口；关闭后丢弃。已保存模板持久保留，切换账号时会清空当前窗口并按新账号读取。管理员和操作员均可把自己的模板应用到新数据集登记表单；应用到已有公共数据集的特征编辑仍需要管理员权限。

## 从已有数据集创建

1. 打开“数据与模型”，点击已配置的数据集名称。
2. 在详情中点击“保存为格式模板”，填写便于辨认的模板名称后保存。
3. 管理员也可在“数据集特征”编辑窗口保存当前格式，无需修改已有资产。

同一账号保存同名模板会覆盖更新该模板。不同账号可以使用相同名称，互相看不到对方的模板。

## 登记后续数据集

新数据集登记需要 `datasets.register`，管理员和操作员均具备；已有公共资产的特征编辑仍需要管理员的 `assets.write`。个人格式模板权限不替代登记或编辑权限。

1. 点击“登记数据集”（管理员入口为“登记资产”），选择数据集并填写当前资产的名称、机器和路径。
2. 在数据集配置区选择格式模板，点击“套用模板”。
3. 检查任务描述等默认值，按当前数据集修改；选择其归一化参数绑定后登记。

模板复用机器人类型、机械臂配置、数据格式、相机名称和字段、状态与动作字段标签、字段形状、数据已有的动作 horizon、采样频率和任务描述等登记信息。模板不保存资产名称、机器、路径、版本、归一化资产 ID、字段组合处理方案或训练参数。

如果原始字段已经拼接了多个分量，可将字段“表示”选为“组合向量（多分量）”。例如，一个 `actions` 字段同时包含位置、旋转和夹爪开度。此时“分量”固定为组合向量，字段的原始形状和 horizon 保留。这个标签不声明字段已经归一化，也不说明内部坐标顺序；训练时仍需配置目标表示、动作分块和归一化规则。组合状态字段按完整宽度使用，动作分块总宽度必须与原始字段一致。

控制台和 Agent 都需要包含该标签的校验支持；旧版 Agent 需更新后再使用新标签预检。原生 OpenPI 继续读取明确的训练组合配置，训练目标表示仍为 EEF 或 Joint。

应用模板只修改当前表单中的格式配置，不修改模板来源数据集，也不会批量改写已登记的资产。应用值视为用户明确选择，数据读取推断不会自动覆盖这些值；仍可手工编辑，训练预检继续验证实际文件。数据中已有的动作 horizon 与新建训练中的模型动作预测长度继续独立配置。

模板列表中可以删除不再使用的模板。删除模板不影响已登记的数据集、历史训练或机器上的文件。模板保存或读取失败时仍可手工填写和登记。

## API

需要个人账号及 `dataset-templates.write` 权限，写操作使用现有 CSRF 校验：

- `GET /api/v1/dataset-format-templates`：当前账号的模板摘要。
- `POST /api/v1/dataset-format-templates`：按名称新建或覆盖，正文为 `{ "name": "…", "profile": { … } }`。
- `GET /api/v1/dataset-format-templates/{template_id}`：读取完整格式。
- `PUT /api/v1/dataset-format-templates/{template_id}`：带 `expected_revision` 更新。
- `DELETE /api/v1/dataset-format-templates/{template_id}`：带 `expected_revision` 删除。

跨账号读取、修改或删除均返回 404。客户端附带 `X-Dataset-Template-User`，防止登录账号切换后继续操作旧账号的模板。每个账号最多保存 100 个模板，请求最多 64 KiB；模板版本冲突时需重新读取。
